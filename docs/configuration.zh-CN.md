# 配置

[English](./configuration.md) · [简体中文](./configuration.zh-CN.md) · [返回 README](../README.zh-CN.md)

安装后打开 `设置 -> Mktero`。

| 设置 | 是否必需 | 作用 |
| --- | --- | --- |
| 转换服务 | 必需 | 选择 MinerU 或 Mistral OCR 4.1 |
| MinerU 服务 | 仅 MinerU | 选择 MinerU 云端，或自部署的 MinerU 4.0 V1 服务 |
| 本地服务地址 | 仅本地 MinerU | 服务根地址，默认 `http://127.0.0.1:8000`。HTTP 只允许回环地址和私网地址 |
| API key | 云端缓存未命中时必需 | 为 MinerU 云端或 Mistral 填写 API key。选择本地 MinerU 时不显示该字段 |
| AI 功能和 Provider 设置 | 可选 | 按厂商分别配置流式输出、模型、密钥、推理强度和超时；阿里云百炼、月之暗面和 MiniMax 可选择国际站或国内站，需与申请 API Key 的站点一致；切换厂商时恢复该厂商上次的设置，未配置过则为空；已知模型会只显示其支持的推理强度 |
| 翻译语言 | 可选 | 简体/繁体中文、日文、韩文、西班牙语、法语或巴西葡萄牙语 |
| 自动翻译 Markdown 选区 | 可选，默认关闭 | 无需再次点击即可翻译稳定的选区；关闭后保留弹窗中的手动操作 |
| 正文字体和字号 | 可选 | 选择阅读字体，并在 14–28 px 间调整字号 |
| 行高、栏宽和对齐 | 可选 | 选择紧凑/标准/宽松行距、窄/标准/宽栏，以及左对齐或两端对齐。默认左对齐 |
| PDF 原文缩略图 | 可选，默认开启 | 显示当前段落对应的 PDF 原貌裁切 |
| 复用转换结果 | 可选 | 复用相同 PDF 内容和解析配置对应的结果 |

MinerU、Mistral 和 AI 凭据会作为普通的未加密首选项存储在当前 Zotero 配置文件中。Mistral
使用同步请求，可以在本地取消，但没有可恢复的服务端任务；MinerU 云端仍保留原有的任务恢复行为。本地 MinerU 服务只在自己的进程里保存任务，服务重启后 Mktero 不会恢复旧任务。开始翻译前，可以使用`测试连接`验证 AI 地址。
