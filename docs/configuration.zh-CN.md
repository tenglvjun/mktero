# 配置

[English](./configuration.md) · [简体中文](./configuration.zh-CN.md) · [返回 README](../README.zh-CN.md)

安装后打开 `设置 -> Mktero`。本页说明所有设置，以及连接和存储方面的规则。

## 账号与转换

| 设置 | 是否必需 | 作用 |
| --- | --- | --- |
| 账号 | 默认的托管转换需要 | 登录或注册 Mktero 账号，用于托管 PDF 转换。面板显示账号资料和转换统计；详见[账号细节](#账号与转换-1) |
| 托管日额度 | 服务支持时显示 | 显示服务端限额、已用、预占、剩余，以及本地时区的重置日期与时间。打开面板、托管请求结束和手动刷新时更新。服务启用时才按 UTC 自然日限制，观察模式不阻断请求 |
| 转换服务 | 可选，默认 Mktero | 转换页提供 Mktero、MinerU 和 Mistral。Mktero 使用账号登录和托管服务；MinerU 和 Mistral 使用你自己的凭据。AI 翻译始终使用你自己的服务商密钥 |
| 转换服务 | 使用自己的 API 时必需 | 选择 MinerU 或 Mistral OCR 4.1 |
| MinerU 服务 | 仅 MinerU | 选择 MinerU 云端，或自部署的 MinerU 4.0 V1 服务 |
| 解析模型 | 仅 MinerU 云端 | 为直连 MinerU 云端操作选择 `VLM`（默认）或 `Pipeline`；每次操作开始时即固定。Mktero 托管转换由服务端决定模型，本地 MinerU 服务不受影响 |
| 本地服务地址 | 仅本地 MinerU | 服务根地址，默认 `http://127.0.0.1:8000`。HTTP 只允许回环地址和私网地址 |
| API key | 云端缓存未命中时必需 | 填写 MinerU 云端或 Mistral 的密钥。选择本地 MinerU 时隐藏该字段 |

## AI 翻译

| 设置 | 是否必需 | 作用 |
| --- | --- | --- |
| AI 功能和服务商设置 | 可选 | 按厂商分别配置流式输出、服务商、模型、密钥、推理强度和超时；详见[服务商配置](#ai-翻译-1) |
| 翻译语言 | 可选 | 简体/繁体中文、日文、韩文、西班牙语、法语或巴西葡萄牙语 |
| 自动翻译 Markdown 选区 | 可选，默认关闭 | 无需再次点击即可翻译稳定的选区。关闭后保留弹窗中的手动操作 |

翻译前，点击 AI 厂商旁的闪电图标（`测试连接`）验证地址。

## 阅读

| 设置 | 是否必需 | 作用 |
| --- | --- | --- |
| 正文字体和字号 | 可选 | 选择阅读字体，并在 14–28 px 间调整字号 |
| 行高、栏宽和对齐 | 可选 | 选择紧凑/标准/宽松行距、窄/标准/宽栏，以及左对齐或两端对齐。默认左对齐。版心随窗口变化，最宽分别为 45rem（窄）、80rem（标准）、120rem（宽）；正文、图、表和代码使用同一宽度 |
| PDF 原文缩略图 | 可选，默认开启 | 显示当前段落对应的 PDF 原貌裁切。阅读器的`排版`面板中也有同一开关 |

阅读器内的操作见[调整阅读视图](./reading.zh-CN.md#调整阅读视图)。

## 细节

### 账号与转换

- 账号只用于托管 PDF 转换。注册需要确认密码，并向邮箱发送 6 位验证码。密码不会保存。
- 调试构建可以更改服务地址；正式构建使用打包进去的生产地址。
- 登录后，面板显示账号昵称、邮箱、注册日期和转换统计。点击名字右侧的铅笔按钮修改昵称。
- 访问令牌和刷新令牌未加密，保存在当前 Zotero 配置文件中。MinerU、Mistral 和 AI 凭据也作为普通的未加密首选项保存在该配置文件中。

如果 MinerU 云端返回 `HTTP 401` 或 `token expired`，请在 `设置 -> Mktero` 更新 MinerU API key。可从 [MinerU 官方 API key 管理页](https://mineru.net/apiManage/token)获取新 key。在浏览器中重新登录不会更新插件中保存的 key。

`解析模型`只作用于直连 MinerU 云端的请求。Mktero 托管转换的模型由服务端决定，不会读取该设置；本地 MinerU 服务沿用自己固定的请求。每次操作在开始时（早于本地导入检查、也早于加载 PDF）就确定模型，因此之后修改设置只影响后续操作；若该项目已有正在运行的任务，再次打开会加入原任务，既不会移动也不会取消它。本版本无法识别的设置值按 `VLM` 处理；在出现该选择之前记录的待续任务同样按 `VLM` 处理。缓存、待续任务和恢复规则见[MinerU 云端解析模型](./conversion.zh-CN.md#mineru-云端解析模型)。

各转换服务的取消和恢复方式不同：

| 转换服务 | 行为 |
| --- | --- |
| Mistral | 使用同步请求，可以在本地取消，但没有可恢复的服务端任务 |
| MinerU 云端 | 保留原有的任务恢复行为，恢复的任务仍使用该任务开始时就固定的解析模型 |
| 本地 MinerU | 只在自己的进程中保存任务。服务重启后，Mktero 不会恢复旧任务 |

### AI 翻译

- 切换厂商时恢复该厂商上次的设置；未配置过则使用空配置。
- 阿里云百炼、月之暗面和 MiniMax 可选择国际站或国内站，需与申请 API Key 的站点一致。
- 对于已知模型，只显示其支持的推理强度。
- 只有选择`自定义或兼容服务`时，才显示自定义地址和协议。
