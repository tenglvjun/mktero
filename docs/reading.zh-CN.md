# 阅读

[English](./reading.md) · [简体中文](./reading.zh-CN.md) · [返回 README](../README.zh-CN.md)

Mktero 将 OCR 结果、多栏文字、公式、表格、图片、列表和代码重排成连续的阅读文档。本页介绍文档导航、PDF 来源、复制、阅读视图和可选的 AI 翻译。

算法步骤中相邻的行内公式分别渲染，保留各自的边界，不改变算法正文、缩进或普通代码。

## 在文档中定位

- 在左栏的`标题`分段浏览目录，在`图表`分段浏览图片和表格索引。
- 预览论文引用、作者单位、图片和表格，无需离开阅读器。
- 按 `Cmd/Ctrl+F` 查找正文。
- 阅读区底部的细进度条显示当前进度。文档长到需要滚动时才显示，专注模式下隐藏。

跳转后，可以用工具栏开头的两个箭头返回或前进，也可以使用快捷键：

| 操作 | Windows / Linux | macOS |
| --- | --- | --- |
| 后退 | `Alt+←` | `Cmd+[` |
| 前进 | `Alt+→` | `Cmd+]` |

两套快捷键在两类平台上都可用。[历史记录规则](#在文档中定位-1)说明哪些跳转会记录，以及何时清空。

## 在 Markdown 与 PDF 之间跳转

OCR 映射把 Markdown 内容块连接到 PDF 的物理页码和区域。来源可靠时，文字、公式、表格和图片都可以跳回 PDF；`复制并附带来源`会复制段落及来源链接。匹配有歧义时不会猜测位置。

从 PDF 打开对应的 Markdown：

1. 在 Zotero PDF 阅读器里选中文字。如果该 PDF 已有可读缓存，选择`在 Markdown 中打开`。
2. 唯一重叠的来源区域会定位到对应段落。如果没有区域与选区重叠，但文字只出现在一个缓存段落中，也能打开该段。
3. 如果该段已有完整译文，`原文`会切为`双语`；已经处于`译文`或`双语`时保持当前视图，不发起翻译请求。

`PDF 原文缩略图`显示当前段落的实时 PDF 裁图，开关在工具栏的`排版`（`Aa`）面板中。

版面证据、页面坐标和 Markdown 范围一致时，Mktero 会从本地 PDF 恢复图表。后台工作线程在原位替换占位图，恢复较慢也不阻塞阅读；原理见[图组恢复流程](./figure-pipeline.zh-CN.md)。

## 脚注与文章信息

MinerU 结果中的脚注以灰色小号引用文字显示在引用它的段落附近，可以查找、添加注释、翻译和复制。点击标为`跳到脚注`的标记可前往脚注，点击脚注开头的标记可回正文；两次跳转都会记入阅读历史。

正文之外的元信息放在折叠区块中：

| 区块 | 内容 |
| --- | --- |
| `文章信息` | 标题和作者行下方的作者单位、联系方式、贡献说明、基金、日期及期刊首页侧栏 |
| `作者简介` | 参考文献之后的作者简介 |
| `报告摘要` | Nature 的 Reporting Summary |
| `图表数据` | 自部署 MinerU 服务高精度档位读出的图表数据；表格仍按表格显示 |

这样第一屏保留标题、作者和摘要。每次打开文档时区块均收起；点击区块标题按钮，或按 `Enter`、`Space` 展开。查找结果、注释或其他跳转指向其中的内容时，会先展开区块；区块内的标题不列入目录。

## 复制公式、代码块与表格

指向行间公式或表格时，顶角会出现复制操作。代码块的复制操作在自身工具栏中。

| 内容 | 操作 | 剪贴板文本 |
| --- | --- | --- |
| 行间公式 | `复制 LaTeX` | 标准 Markdown：以 `$$` 块包住渲染公式的 TeX，包含 Mktero 为排版所做的 OCR 修正 |
| 代码块 | `复制代码` | 代码块文本 |
| 表格 | `复制为 Markdown` | Markdown 表格 |
| 表格 | `复制为 CSV` | 逗号分隔的行，单元格为纯文本 |

公式复制和表格的`复制为 Markdown`还会附带 HTML，粘贴到 Zotero 笔记时保留公式或表格。支持 TeX 渲染的 Markdown 编辑器也能显示公式。

使用 `Cmd/Ctrl+C` 复制段落时，文本为标准 Markdown，公式写成行内 `$…$` 或 `$$` 块。内容含公式或表格时，还会附带供 Zotero 笔记使用的 HTML；两者都没有时只复制文本。选区菜单中的`复制并附带来源`会生成带 Markdown 公式和来源链接的引用，粘贴到 Zotero 笔记后公式会排版，链接可点击。

这些操作只读取渲染后的文档，不发送任何内容，也不改动缓存的 OCR Markdown、校对或评论。[复制规则](#复制公式代码块与表格-1)说明表格转换、公式与单元格内选区，以及其他应用中的粘贴效果。

## 调整阅读视图

在工具栏中打开`排版`（`Aa`），可以选择：

- 正文字体，以及 14 至 28 px 的字号。
- 紧凑、标准或宽松行距。
- 窄栏、标准或宽栏。
- 左对齐（默认）或两端对齐。
- 默认开启的`PDF 原文缩略图`。

栏宽随窗口变化，达到所选最大宽度后停止增长；文字、图片、表格和代码共用同一宽度。[配置](./configuration.zh-CN.md)也提供这些选项，并列出默认值与宽度上限。

`专注模式`会隐藏侧栏，以及后退/前进、引用图谱、`保存与导出`和 `⋯` 等工具栏控件，同时隐藏进度条。点击`退出专注模式`或按 `Escape` 离开；如果阅读器菜单或查找仍打开，`Escape` 会先关闭它们。

## 使用 AI 翻译

### 翻译全文

1. 在 [Mktero 设置](./configuration.zh-CN.md)中配置并启用 AI 翻译。
2. 点击`翻译全文`。只有主动请求才会开始，翻译不会重写原始 Markdown。
3. 在`原文`、`译文`和连续的`双语`视图间切换；部分完成的翻译可以按内容块继续。

已有完整译文时，`译文`标签会打开语言菜单。菜单末尾的`重新翻译全文`按当前语言重新翻译整篇文档。

Mktero 把文章分成受控的 Markdown 批次，保护公式、引用、链接、代码、图片和结构占位符，最多同时执行 5 个请求。缓存与校对的关系见[翻译规则](#使用-ai-翻译-1)。

### 翻译选区

1. 在`原文`或`双语`的原文侧选中术语或段落。
2. 点击选区弹窗操作行末尾的`翻译选中文本`。加载、结果或错误会在下方的紧凑面板中按需展开。
3. 流式服务会逐步显示译文，期间仍可取消；非流式服务在完成后一次显示结果。
4. 成功后，可选择`再次翻译选区`，或用`复制选区译文`复制纯文本。

`自动翻译 Markdown 选区`默认关闭。开启后，选区稳定一小段时间便会发起一次受控请求。`双语`的译文侧、`译文`视图和已保存的 HTML 快照不提供选区翻译。

每次请求只把所选文字发送给你配置的 AI 服务，可能产生服务商费用。结果只留在弹窗中，不修改 Markdown 或评论，也不写入全文翻译缓存。

## 细节

### 在文档中定位

历史会记录：打开论文引用、表格引用或图表引用；选择目录条目或注释；跟随文档内链接；以及查找。同一次查找中逐个查看匹配只算一次跳转，手动滚动不产生记录。

后退会保存离开的位置，便于前进返回；后退后再发起新跳转会丢弃原有前进记录。每篇打开的文档在内存中最多保留 50 个位置，关闭标签页或替换文档（例如重新解析）会清空。

### 在 Markdown 与 PDF 之间跳转

MinerU 文档保留 PDF 原生安全 HTTP(S) 链接注释和 MinerU 超链接的原始目标，包括 URL 中的下划线，不会从显示文字推测目标。目标缺失或不安全时显示普通文字。Markdown 在隔离的 shadow root 中渲染，链接和图片均受限制。

Mktero 识别常见出版商格式的图注，包括空 OCR 图片之后的 `Figure N | ...`，因此缓存文档的正文图表引用仍可预览。

Mktero 在本地读取 PDF 文字层来修复 MinerU 阅读文本：接合在句号处被跨页或跨栏切开的段落，按类型调整无章节编号论文的标题层级，并在排版 PDF 中恢复被 OCR 改写的单个词，例如姓名或作者原本的拼写。

### 脚注与文章信息

#### 放置与识别

- 页底脚注放在本页第一个带对应标记的段落之后，标记可以是上标数字、`*` 或 `†`。
- 找不到标记时，放在本页最后一个段落之后，不越过标题。
- 表注和图注使用相同样式，紧跟对应表格或图片。
- 识别依据是版面和页面文字。特殊印刷标记可能让脚注落在别的段落后；未识别为元信息的内容留在正文。

Mktero 隐藏出版商刊头、首页版权提示、重复页眉页脚及页码。长论文标题保留标题样式。

如果确认出版社封面之后含有同一论文标题以及摘要或引言，MinerU 阅读文档会采用正文首页的标题和作者，移除封面上重复的标题、署名，以及投稿提示、浏览量、相关文章控件和关联图标。引用、DOI 和出版日期仍与正文首页元信息一同保留在`文章信息`中，PDF 的物理页码和来源位置不变。

#### 保存与导出后的区块

[快照](./references-and-export.zh-CN.md#保存便携快照)和 [Zotero 笔记](./annotations.zh-CN.md#在阅读器旁写-zotero-笔记)以加粗区块名加内容的方式显示。[Markdown](./references-and-export.zh-CN.md#导出-markdown) 和 [Obsidian](./references-and-export.zh-CN.md#导出到-obsidian) 导出保留普通文字内容；区块标记为 HTML 注释，在 Obsidian 中不可见。

### 复制公式、代码块与表格

#### 公式与表格

- 公式过大，或使用了 Mktero 拒绝渲染的命令时，只复制源码。在阅读器中打开已保存的快照时，其中的行间公式也有相同复制操作。
- GFM 渲染的表格通过`复制为 Markdown`保留原 GFM 块，粘贴回去仍是同一张表。
- 论文自带的 HTML 表格及快照中的所有表格会转成管道表。`thead` 行作为表头，没有时提升首行；合并单元格展开，对齐取自单元格自身的 `align` 属性，粗体、斜体、代码、链接、公式和上下标保留含义。
- CSV 将行内格式、链接和公式还原为屏幕所见的文字，引用保留 `[1]` 标记。含逗号或引号的单元格按 RFC 4180 加引号，表题不计入数据。
- 表格超出阅读器导出预算时会拒绝复制，不会截断。

#### 键盘选区与粘贴目标

`Cmd/Ctrl+C` 使用阅读器排版的 TeX，将 HTML 表格转为含公式的管道表，并省略隐藏的页眉、页脚和页码标记。附带的 Zotero 笔记 HTML 包含每个公式，单字母 `$i$` 也不例外。

| 选区 | 结果 |
| --- | --- |
| 渲染后的公式内部 | 整个公式 |
| 表格单元格内部 | 该单元格的文字和公式 |
| 渲染表格的多个单元格 | 将所选单元格复制成表格 |
| 过大或被拒绝渲染的公式 | 公式源码 |
| 很长且包含大量公式的段落 | 仅 Markdown |

文字处理软件、浏览器编辑器等读取剪贴板 HTML 的应用，收到的段落中公式以 `$` 包住的 TeX 显示；在那里使用“粘贴为纯文本”可得到 Markdown。CSV 和代码复制不受这些公式、表格规则影响。

### 使用 AI 翻译

#### 缓存与校对

译文按源内容、服务商、协议、模型、语言、推理强度和提示词版本独立缓存，部分工作可继续完成。Mktero 更新后重新读取 MinerU 结果时，未变的块保留译文，变化的块标记为待翻译。

| 变化 | 译文行为 |
| --- | --- |
| 本地校对删除内容块 | 其他块保留译文，删除的块不再出现在`双语`视图中 |
| 恢复已删除的块 | 保留早期源版本，因此即使已翻译过校对后的文档，也能复用该块的完整译文 |
| 删除引用标记 | 受保护占位符能唯一映射时保留该块译文；有歧义时仍待单块重译 |
| 修改已翻译的块 | 其他译文不变，该块标为待翻译，并询问是否仅重译该块 |
| 恢复全部校对 | 有原始 Markdown 的完整缓存译文时直接载入，不发起新的 AI 请求 |

#### 服务商与连接规则

Mktero 通过 Vercel AI SDK Core 支持 OpenAI、Anthropic、Google Gemini、DeepSeek、阿里云百炼、Moonshot/Kimi、MiniMax，以及自定义 OpenAI 兼容或 Open Responses 服务。远程地址必须使用 HTTPS；Ollama、LM Studio 等回环服务可使用 HTTP。自定义 OpenCode Go 地址（例如 `https://opencode.ai/zen/go/v1`）还会接收每个会话的 `x-opencode-session` 请求头。

#### 推理强度

Zotero 启动时，Mktero 从 `https://models.dev` 获取一次目录，只保存在内存中，退出时释放。已知模型的选项如下：

- 不支持推理的模型只提供 `none`。
- 不能关闭思考的模型不提供 `none`。
- 其他已知模型列出支持的档位，可能包含 `on`、`minimal` 或 `max`。

模型未知或目录获取失败时，提供 `none`、`low`、`medium`、`high` 和 `xhigh`。推理过程不会作为译文保存。
