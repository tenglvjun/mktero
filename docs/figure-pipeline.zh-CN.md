# 图组恢复流程

[English](./figure-pipeline.md) · [简体中文](./figure-pipeline.zh-CN.md) · [返回 README](../README.zh-CN.md)

证据足够充分时，Mktero 会从本地 PDF 按阅读分辨率重建完整图组（144 DPI，长边 1600 像素，而不是印刷分辨率），替换阅读流中的 OCR 片段。光栅化在后台 Worker 中完成，阅读界面和 Zotero 其他操作保持响应。MinerU 支持基于坐标的区域恢复；MinerU 和 Mistral 都支持下文基于图片证据的处理。证据不足时，Mktero 保留服务返回的原图片和文字。

## 区域恢复

图组候选由服务返回的内容块和精确的 Markdown 范围构建。只有版面证据、页面坐标和 Markdown 范围三者一致时，才会从本地 PDF 裁切完整图组。生成的本地 PNG 保留 `2x2`、`4x4`、缺角、跨行和不规则排列。

- 图内 OCR（属于图表本身的标签和文字）只有在裁切成功后才会从阅读流移除。
- 图注仍可选择、搜索和翻译，包括图号后使用破折号的期刊格式（`Figure 1—A and B: ...`）。面板字母和分组标题保留在图内，完整图注只在图下显示一次，正文中的图表引用不受影响。
- 本地恢复流程会在无需再次上传 OCR 的情况下升级兼容缓存，并保留用户的校对内容。已恢复完成的图不会再次光栅化。
- 有歧义、旋转或无法验证的图组保留原图片和文字。

已确定归属的 MinerU 图组，其 OCR 坐标仍可能漏掉共享标题或最外侧子图。只有原始 PDF 图片唯一、每个面板的像素一致且 PDF 图注匹配时，Mktero 才将裁切范围扩展到原图边界，完整图注仍单独保留。扩展范围不能碰到其他版面内容或原区域以外的 PDF 原生文字；核验失败则保留原本安全的裁切。该机制不推断独立图片之间的关系，也不扩展到任意向量图。

### MinerU 文档重写

1. Mktero 依据 MinerU 的 layout 写出阅读用 Markdown。每个图组的图片、图注和图内文字从一开始就有精确的 Markdown 范围，不靠文字匹配。
2. 合成后的图写回它第一个成员所在的位置。整篇文档按同一份 layout 重新写出，来源映射仍然精确。
3. 未完成的恢复不写入缓存。重启后从保存的 MinerU 结果重新执行；该结果不存在时，过渡文档仍可阅读。

## 渐进式渲染

转换完成后即可开始阅读。尚未拼好的图组显示动画占位（lucide 图片图标加旋转 loader）。阅读器逐张替换已完成的图，不会重建整篇文章，因此慢的图不会拖住其余内容。

普通区域裁切在后台 Worker 中复用同一页的光栅化结果；原图边界和像素核验可能额外渲染页面。关闭阅读标签页不会停止正在进行的恢复，任务会继续并在完成后更新缓存。所有图表处理完成前，导出与保存快照保持禁用。

## 标签面板

当三类证据一致时，MinerU 和 Mistral 都可以从单张完整 PDF 图片中恢复带标签的面板：图片边界、匹配的 PDF 图注，以及每个面板的像素。

独立的 OCR 标签行（如 `(A)`、`(B)` 及其全角形式）只有在完整图片恢复后才会从正文移除。正文引用和图注内部的标签保持原样。

## 无编号的图形摘要

对于 MinerU 结果，当多个面板和图内文字属于 PDF 中的同一张原始图片时，Mktero 可以恢复无编号的图形摘要。替换碎片前，会核验页面坐标、原图边界及每个面板的像素。图内标题、标签和说明保留在原来的位置，不再重复成为正文段落，也不会被拼成不存在的图注。图外正文继续保留在阅读流中。

额外核验期间仍显示 OCR 碎片，文档处理完成后一起替换。原图边界、文字归属或像素无法验证时，保留原碎片。该恢复使用本地 PDF 和保存的 MinerU 结果，无需再次上传 OCR。

## 重新合并被错位标题拆开的图组

当 PDF 文字位置、共享图注和每张图片的像素都能验证关系时，两家服务都可以重新合并被错位标题拆开的图组，向量图表也包含在内。

标题保留在图组上方并可搜索。图片按 PDF 行序恢复，陈旧的版面标记会重建，跨整行的图片同样处理。

## 服务支持

- **MinerU：** 区域恢复使用 `layout.json` 的页面尺寸，且该尺寸必须与 PDF 页面一致。90° 或 270° 旋转会交换宽高，每一维的相对误差不超过 1%。尺寸不一致的页面保持 MinerU 返回的图组原样。
- **Mistral：** 像素尺寸无法确定 PDF CropBox 的原点和旋转方向，且这一点尚未独立验证。因此当前生产适配器不执行基于坐标的区域恢复，而是保留原图片和 OCR 文字。上述基于图片证据的处理仍然适用。
- **缓存：** MinerU 与 Mistral 使用独立的解析配置，图组结果分别缓存，不会跨服务复用。

## 资源上限

图组处理对页数、版面内容块、候选比较次数、裁切像素、画布内存、生成字节数和渲染时间都有上限。超出预算的内容会保留，不作裁切。图组回归语料见[开发](./development.zh-CN.md)。
