# 当前限制

[English](./limitations.md) · [简体中文](./limitations.zh-CN.md) · [返回 README](../README.zh-CN.md)

- 文献列表中的 Markdown 列只在 Mktero 确认该 PDF 于当前转换设置下仍有可用本地缓存后显示。准备中的加载动画只在本次会话有效，关闭扩展后消失。它不会扫描整个文库，不修改条目，也不会同步。清空缓存、缓存过期或解析配置变化后，完成标记会熄灭。此功能出现之前转换过的条目，要等到该缓存被再次打开或写入后才会显示。批量准备会在去重后加入全部选中的 PDF，并且同时转换 3 篇。
- 仅支持本地 PDF 附件。扫描版 PDF 可以通过 OCR 转换，但没有文字层时无法生成精确的 Zotero 高亮。
- 来源跳转依赖 Provider 返回的内容块和坐标；MinerU 云端、本地 MinerU 和 Mistral 使用独立的解析配置和缓存，旧缓存可能仍可阅读但没有来源链接。
- MinerU 的页脚注（页面底部的作者单位、基金信息和内容注释）暂时不在阅读文档中显示。
- MinerU 云端结果只按 OCR 内容块定位文字，不按行定位，所以 Markdown 段落跳回 PDF 时定位到整个内容块。跨页、跨栏或隔着图表合并的段落，每一部分各保留一个位置。
- 本地 MinerU 模式连接 MinerU 4.0 V1 服务。它不会从该服务的结果还原图片，本地服务重启后也不能恢复之前的任务。
- 只有一个来源区域盖住 PDF 选区，或选区文字只出现在一个已缓存段落且没有任何来源区域与选区重叠时，才会打开对应的 Markdown。有歧义、重复、尚未缓存或无法选择的文字仍留在 PDF 中，不会开始转换。Zotero 最多提供两页选区几何。
- Markdown 选区会与 PDF 自身的文字层比对。被抽错到超出容忍范围的段落、没有文字层的扫描页，以及无法靠上下文区分的重复段落，会保留为本地标注并可重试。
- 目前显示文本高亮和下划线，不显示独立便签、图片/区域标注或手写标注。
- Markdown 图片仅限当前结果压缩包中的 GIF、JPEG、PNG 和 WebP；远程图片会被阻止。
- 链接协议仅允许 `http`、`https`、`zotero` 和文档片段。
- 校对模式只能编辑或删除已有内容块。公式、MinerU 使用美元符号包裹的引用标记和已匹配的划区文字受到保护，其周围文字仍可编辑；修改划区文字前必须先删除划区，且含受保护内容的内容块不能整段删除。文档结构、图片和原始 HTML 同样不能改变。
- AI 翻译是可选的缓存阅读层，不修改源 Markdown，也不会写入快照。
- 选区翻译是独立的按需阅读辅助，只能从 Markdown 阅读视图的原文侧使用，不写入缓存，可能产生 AI Provider 费用。
- 在 Windows 上，从 Markdown 阅读区复制时可能撞上另一个程序正打开着剪贴板，Zotero 这时会保留剪贴板原有内容且不报错。Mktero 每次从阅读区复制后会读回剪贴板，没写进去就再写一次；约两秒后仍未写入，阅读区工具栏会提示，剪贴板保持原有内容。选区仍可见但焦点在窗口其他位置时按 Ctrl+C，也会复制阅读区的选区。在输入框、笔记或 PDF 里复制不受影响。
- 压缩包、Markdown、图片、来源映射、PDF 索引和 KaTeX 渲染都有本地资源上限，超限时会安全停止处理。无法渲染的 Markdown 内容块（例如嵌套数百层的列表）会显示为转义后的源文本，文档其余部分保持原有格式。
