# 当前限制

[English](./limitations.md) · [简体中文](./limitations.zh-CN.md) · [返回 README](../README.zh-CN.md)

- 文献列表中的 Markdown 列只在 Mktero 确认该 PDF 于当前转换设置下仍有可用本地缓存后显示。准备中的加载动画只在本次会话有效，关闭扩展后消失。它不会扫描整个文库，不修改条目，也不会同步。清空缓存、缓存过期或解析配置变化后，完成标记会熄灭。此功能出现之前转换过的条目，要等到该缓存被再次打开或写入后才会显示。批量准备会在去重后加入全部选中的 PDF，并且同时转换 3 篇。
- 仅支持本地 PDF 附件。扫描版 PDF 可以通过 OCR 转换，但没有文字层时无法生成精确的 Zotero 高亮。
- Mktero 账号托管转换和 MinerU 云端每个 PDF 最多 200 页。超过时在上传前停止，并提示拆分 PDF 或更换转换服务；已缓存的 Markdown 和校对内容仍可打开。页数在本机读取；读不出页数（例如加密 PDF）时照常发送，由服务端判断。本地 MinerU 和 Mistral 不做这项检查。
- 来源跳转依赖 Provider 返回的内容块和坐标；MinerU 云端、本地 MinerU 和 Mistral 使用独立的解析配置和缓存，旧缓存可能仍可阅读但没有来源链接。
- 只有当脚注在同一章节内、位于标记之后，并且开头重复了这个标记时，正文中的脚注标记才会链接到它。放置时没有找到标记的脚注（例如 OCR 文字中没有的 `††`）不带链接。文章信息、作者简介和报告摘要这几个折叠区块根据页面版面和文字识别，格式特殊的首页信息可能仍留在正文中。
- MinerU 云端结果只按 OCR 内容块定位文字，不按行定位，所以 Markdown 段落跳回 PDF 时定位到整个内容块。跨页、跨栏或隔着图表合并的段落，每一部分各保留一个位置。
- 在句号处被换页或换栏切开的 MinerU 段落，只有在 PDF 有文字层、能看出断点前一行写满且后一行没有缩进、并且论文本身使用首行缩进时才会接回。没有文字层的 PDF（扫描件）中这类段落保持分开。没有章节编号的论文，大纲层级依据同一文字层中的标题字体样式确定；样式无法形成嵌套或 PDF 没有文字层时，这些标题保持同一层级。
- MinerU 的 OCR 模型有时会写出它“认为应该是”的文字，而不是印刷的文字。对于排版生成、文字层与 MinerU 几乎处处一致的 PDF，单个不同的单词会恢复为印刷文字，因此作者原文的笔误或拼写会按印刷保留；MinerU 重复输出的标题只保留一份。扫描版 PDF 的文字层来自较早的 OCR，不会被采用，保持 MinerU 的识别结果，其中识别错的单词也会保留。
- 本地 MinerU 模式连接 MinerU 4.0 V1 服务。结果从压缩包里的 `middle_json.json` 读取，阅读规则与 MinerU 云端相同（页脚注、跨页段落与续表、隐藏页面装饰、来源跳转）；压缩包里没有可读的 `middle_json.json` 时，保留该服务自己的 Markdown。结果和其他保存的 MinerU 结果放在一起，Mktero 更新后不需要该服务即可重新读取。它不会从 PDF 还原裁剪的图片，本地服务重启后也不能恢复之前的任务。
- 只有一个来源区域盖住 PDF 选区，或选区文字只出现在一个已缓存段落且没有任何来源区域与选区重叠时，才会打开对应的 Markdown。有歧义、重复、尚未缓存或无法选择的文字仍留在 PDF 中，不会开始转换。Zotero 最多提供两页选区几何。
- Markdown 选区会与 PDF 自身的文字层比对。被抽错到超出容忍范围的段落、没有文字层的扫描页，以及无法靠上下文区分的重复段落，会保留为本地注释并可重试。
- 目前显示文本高亮和下划线，不显示独立便签、图片/区域注释或手写注释。
- `添加至笔记`需要 PDF 位置。尚未同步到 PDF 的本地高亮，或本地 PDF 索引无法定位的选区（找不到，或有歧义），会被拒绝并说明原因。Mktero 不会在没有来源的情况下插入。
- 在笔记里，用`添加至笔记`加入的公式位于旁边高亮之外，因此没有高亮颜色，也不能跳回页面。跨页的段落、论文以 HTML 携带的表格里的公式，以及 Mktero 无法在 Markdown 中定位的注释，保留 Zotero 的纯文本。写在表格单元格里的 `$$…$$` 在阅读器中不排版，复制时按原样复制。
- 笔记中的引用会打开 Zotero 的 PDF 阅读器，而不是 Mktero。
- 没有父条目的独立 PDF 没有子笔记。
- 标签页内的笔记编辑器是 Zotero 的笔记编辑器。如果无法在标签页内显示，笔记会改在 Zotero 的笔记窗口中打开。
- Markdown 图片仅限当前结果压缩包中的 GIF、JPEG、PNG 和 WebP；远程图片会被阻止。
- 链接协议仅允许 `http`、`https`、`zotero` 和文档片段。
- 校对模式只能编辑或删除已有内容块。公式、MinerU 使用美元符号包裹的引用标记和已匹配的划区文字受到保护，其周围文字仍可编辑；修改划区文字前必须先删除划区，且含受保护内容的内容块不能整段删除。文档结构、图片和原始 HTML 同样不能改变。
- AI 翻译是可选的缓存阅读层，不修改源 Markdown，也不会写入快照。
- 选区翻译是独立的按需阅读辅助，只能从 Markdown 阅读视图的原文侧使用，不写入缓存，可能产生 AI Provider 费用。
- 在 Windows 上，从 Markdown 阅读区复制时可能撞上另一个程序正打开着剪贴板，Zotero 这时会保留剪贴板原有内容且不报错。Mktero 每次从阅读区复制后会读回剪贴板，没写进去就再写一次；约两秒后仍未写入，阅读区工具栏会提示，剪贴板保持原有内容。选区仍可见但焦点在窗口其他位置时按 Ctrl+C，也会复制阅读区的选区。在输入框、笔记或 PDF 里复制不受影响。
- 压缩包、Markdown、图片、来源映射、PDF 索引和 KaTeX 渲染都有本地资源上限，超限时会安全停止处理。无法渲染的 Markdown 内容块（例如嵌套数百层的列表）会显示为转义后的源文本，文档其余部分保持原有格式。
