# 当前限制

[English](./limitations.md) · [简体中文](./limitations.zh-CN.md) · [返回 README](../README.zh-CN.md)

本页按转换、阅读、注释和本地数据归纳当前限制。格式相关规则和清理检查放在文末[细节](#细节)中。

## PDF 与转换

- 仅支持本地 PDF 附件。扫描版 PDF 可以通过 OCR 转换，但缺少文字层时无法生成精确的 Zotero 高亮。
- Mktero 账号托管转换和 MinerU 云端每个 PDF 最多 200 页。超过时在上传前停止，提示拆分 PDF 或更换转换服务。已缓存的 Markdown 和校对仍可打开。
- 页数在本机读取。读不出页数（例如加密 PDF）时照常发送，由服务端判断。本地 MinerU 和 Mistral 不做这项检查。

## llm-for-zotero 本地导入

- 每次只处理一个 PDF 的本地缓存。要求有 `full.md`，以及带有效页码和区域坐标的标准内容列表，或受支持的版面数据。
- 不支持纯 Markdown、旧版散装 Markdown、尚未恢复到本机的同步 ZIP，以及缺少区域坐标的本地 MinerU V1 内容列表。兼容性取决于结果格式，不能只看插件版本。
- 必要图片必须可用或能安全恢复。裁图关联有歧义、页面坐标不受支持时可能无法导入。本地导入 PDF 上限为 256 MiB，同时受现有文档和图片资源上限约束。
- 附件元数据和缓存来源记录不能证明旧解析结果匹配当前 PDF。菜单只探测本地候选，点击导入后才校验、复制并打开结果。父条目有多个候选 PDF 时，从子菜单选择目标附件。

依赖已保存副本前，请阅读[导入副本的保留与回退规则](#llm-for-zotero-本地导入-1)。

## 缓存与批量准备

- 文献列表中的 Markdown 列，只有在 Mktero 确认该 PDF 于当前转换设置或选定导入结果下仍有可用本地缓存后才显示。它不扫描文库、不修改条目，也不同步。
- 清空缓存会熄灭完成标记。解析配置变化会改变所用的转换缓存；只有导入选择而没有可读内容时不会标为就绪。此列出现之前转换过的条目，要等缓存再次被打开或写入后才显示标记。
- 准备中的加载动画只在当前会话有效，扩展关闭后消失。批量准备去重后加入全部选中 PDF，同时转换 3 篇。
- 确认附件永久删除后，孤立缓存不设额外保留期，但清理前必须完成保守的本地检查。详见[清理检查](#缓存与批量准备-1)。

## 阅读与跳转

- 来源跳转依赖服务商返回的内容块和坐标，旧缓存可能仍可阅读但没有来源链接。MinerU 云端、本地 MinerU 和 Mistral 使用独立的解析配置和缓存。
- MinerU 云端按 OCR 内容块定位，不按行定位。Markdown 段落跳回 PDF 时定位到整个内容块；跨页、跨栏或隔着图表合并的段落，每一部分各保留一个位置。
- 脚注链接、折叠文章信息、段落修复和标题层级依赖版面或文字层。具体条件见[阅读细节](#阅读与跳转-1)。

## 注释与笔记

- Markdown 选区与 PDF 文字层比对。文字抽取错误超过容忍范围、扫描页没有文字层，或重复段落无法靠上下文区分时，会保留为本地 Markdown 注释，可稍后重试。
- 显示文本高亮和下划线，不显示独立便签注释、图片/区域注释或手写注释。
- `添加至笔记`需要 PDF 位置。尚未同步到 PDF 的本地高亮，或本地 PDF 索引找不到或无法区分的选区，会被拒绝并说明原因。Mktero 不会在没有来源的情况下插入。
- 笔记中的引用打开 Zotero PDF 阅读器。没有父条目的独立 PDF 没有子笔记。
- 标签页内使用 Zotero 的笔记编辑器；无法在标签页内显示时，改在 Zotero 笔记窗口中打开。

笔记中的公式处理见[注释与笔记细节](#注释与笔记-1)。

## 校对

校对模式只能编辑或删除已有 Markdown 内容块：

- 公式和 MinerU 美元符号包裹的引用标记周围的文字可编辑。
- 这些标记和带注释的文字受到保护，所在内容块不能删除。修改带注释的文字前，先删除注释。
- 文档结构、图片和原始 HTML 仍受保护。

## 翻译

- AI 翻译是可选的缓存阅读层，不修改源 Markdown，也不写入快照。
- 选区翻译是独立的按需阅读辅助，只能从 Markdown 阅读视图的原文侧使用，不写入缓存，可能产生 AI 服务商费用。

## 复制与剪贴板

在 Windows 上，从 Markdown 阅读区复制时，其他程序可能正占用剪贴板，Zotero 会保留原有内容且不报错。Mktero 每次复制后读回剪贴板，未写入则重试；约两秒后仍未写入时，工具栏会提示，剪贴板保留原有内容。

选区仍可见但焦点在窗口其他位置时，Ctrl+C 也会复制阅读区选区。在输入框、笔记或 PDF 中复制不受影响。

## 资源上限

- Markdown 图片仅限当前结果压缩包中受支持的 GIF、JPEG、PNG 和 WebP 文件。远程图片会被阻止。
- 链接只允许 `http`、`https`、`zotero` 和文档片段。
- 压缩包、Markdown、图片、来源映射、PDF 索引和 KaTeX 渲染都有本地资源上限，超限时安全停止处理。
- 无法渲染的 Markdown 内容块（例如嵌套数百层的列表）显示为转义后的源文本，文档其余部分保持原有格式。

## 细节

### PDF 与转换

本地 MinerU 模式连接 MinerU 4.0 V1 服务，从压缩包的 `middle_json.json` 读取结果。阅读规则与 MinerU 云端相同：页脚注、合并段落与续表、隐藏页面装饰和来源跳转。没有可读的 `middle_json.json` 时，保留服务自己的 Markdown。

结果与其他保存的 MinerU 结果放在一起，Mktero 更新后无需该服务即可重新读取。本地 MinerU 不会从 PDF 还原裁剪图片，服务重启后也不能恢复之前的任务。

### llm-for-zotero 本地导入

导入副本使用 Mktero 本地缓存，受手动清理、附件永久删除后的[孤立缓存清理](./conversion.zh-CN.md#本地缓存清理)、损坏条目自愈和配置文件所在文件系统可用性影响。单个压缩包、文档和图片等资源仍受安全上限约束。

- 只删除 llm-for-zotero 源缓存不影响保留的 Mktero 副本。保留的原始结果可离线重建文档；需要再次导入时，应保留原结果。
- 如果选定导入结果的本地内容全部缺失，之后普通的`使用 Mktero 阅读 Markdown`会使用当前转换服务，可能上传 PDF。
- 导入失败、内容损坏、读取错误或取消不会触发转换。导入操作本身始终只在本地进行。
- 主动重新解析也使用当前服务，可能上传 PDF。
- 源结果的识别错误和显示问题仍可能保留在导入文本中。

### 缓存与批量准备

清理检查采用以下上限：

| 检查 | 上限或行为 |
| --- | --- |
| 文库枚举 | 最多 50,000 个条目 |
| 核对批次 | 最多 100 个条目，或累计读取 PDF 达到 32 MiB 后让出 |
| 继续扫描 | 250 ms 后从保存的位置继续，不从头重扫 |
| 单个 PDF | 可使该批读取量超过 32 MiB，但单文件不得超过 256 MiB |
| 大小不同的 PDF | 无需计算哈希 |

回收站和有效共享引用会保护数据。只有相关附件或缓存的占用才会延后清理，无关论文的阅读不阻塞。文库不可访问、扫描不完整、归属不明或共享引用无法确认时保留相关数据；删除失败会重试。

枚举会越过缺失或无法读取的 PDF 继续处理。不确定性只影响无法用已核实本地文件信息排除的候选：

- 完全缺失的 PDF 不会一直保住无关缓存。其 Markdown、原始转换结果和 PDF 文本索引可由转换重建，因此会被释放；校对和阅读位置无法重建，继续保留。
- 文件仍存在但无法核实、检查中 PDF 发生变化或扫描不完整时，仍保留全部候选数据。旧同步 MD5 或历史归属哈希不能安全排除候选。

设置页说明原因，显示已释放数量，列出已释放、无法确认的条目及本地缺少的 PDF，并提供`重新检查`。实际清理时间取决于这些检查能否完成，并非通知短延迟结束就一定删除。此前已登记的永久删除记录适用同一规则；归属未知的历史数据继续留在磁盘上。

### 阅读与跳转

脚注与文章信息：

- 只有脚注在同一章节内、位于标记之后，且重复该标记时，正文标记才会链接到它。没有找到标记的脚注（例如印刷的 `††` 未出现在 OCR 文字中）不带链接。
- 折叠的文章信息、作者简介和报告摘要根据版面与文字识别，格式特殊的首页信息可能仍留在正文中。
- 出版社封面清理要求多个不同的平台操作标签、引用/链接信息，以及下一页的同名标题和摘要或引言。证据不足的页面、未明确关联操作文字的图片会保留；不会仅凭尺寸小就判定为装饰。

段落与标题：

- 在句号处被换页或换栏切开的 MinerU 段落，只有当 PDF 文字层显示断点前一行写满、后一行没有缩进，且论文本身使用首行缩进时才接回。没有文字层的扫描 PDF 保持分开。
- 无编号大纲依据同一文字层中的标题样式分层。样式无法嵌套或没有文字层时，标题保持同一级。
- MinerU OCR 有时会输出它预期的文字。对于排版生成且文字层与 MinerU 几乎处处一致的 PDF，单个不同的单词恢复为印刷文字，保留作者原文的笔误或拼写；MinerU 重复输出的标题只显示一次。
- 扫描 PDF 的文字层是较早的 OCR，不用于上述修复。保留 MinerU 的识别结果，包括误识别的单词。

从 PDF 选区打开 Markdown：

- 必须有一个来源区域覆盖选区，或选区文字只出现在一个已缓存段落，且没有来源区域与选区重叠。
- 有歧义、重复、尚未缓存或无法选择的文字留在 PDF 中，不开始转换。
- Zotero 最多提供两页选区几何信息。

### 注释与笔记

通过`添加至笔记`插入的公式位于旁边高亮之外，因此没有高亮颜色或返回页面的链接。

以下情况保留 Zotero 的纯文本：

- 跨页段落。
- 论文以 HTML 携带的表格中的公式。
- Mktero 无法在 Markdown 中定位的注释。

表格单元格里的 `$$…$$` 在阅读器中不排版，复制时按原样复制。
