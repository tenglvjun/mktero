显式导入受支持的 llm-for-zotero 本地结果时，Mktero 在这台电脑上读取原缓存和当前 PDF，不改动原缓存。导入本身及重新打开已保存副本可以离线进行，无需账号或转换服务密钥，不上传 PDF 或结果。Mktero 保存适配后的结果和图片的独立副本，不包含 PDF 副本、完整来源元数据或上游绝对路径；本地导入选择索引记录这个附件选用了哪个快照，不包含源路径。这些副本不由 Mktero 同步，仍受缓存过期、容量上限和手动清理影响。只删除 llm-for-zotero 源缓存，不影响从 Mktero 副本离线阅读。Mktero 优先使用已保存的校对和已生成的阅读文档；保留的原始结果也可离线重建文档。如果选定导入结果的本地内容全部缺失，之后通过普通的`使用 Mktero 阅读 Markdown`打开时，会使用当前转换服务，可能把完整 PDF 发送到那里。导入失败、内容损坏、读取错误或取消不会触发转换，导入操作本身始终只在本地进行。主动选择重新解析也会使用当前转换服务，可能发送完整 PDF。可选的翻译和文献操作仍分别遵循下述数据流。

Mktero 不会把 PDF 注释、本地 PDF.js 索引、Zotero 笔记、完整条目记录、本地路径或缓存 Markdown 发送给文献/PDF Provider。Mktero 不会把笔记发送到任何地方。只有标题的文献在用户明确点击“导入文献”后才会发送受限的引用文本；唯一的高置信度匹配会自动继续，不确定的匹配仍需用户确认。引用与文献请求始终匿名访问 Provider，只包含上表所述的受限引用文本、规范化标识符和已确认元数据，不会发送 Zotero key 或 PDF 字节。翻译请求包含受保护的 Markdown 和指令；如果占位符校验连续失败，最后一次重试只发送受影响内容块中的普通文本片段。选区翻译请求只包含选中文本，不会写入全文翻译缓存。日志不会写入 API Token、预签名地址、PDF 字节或带认证的响应。

“报告问题”把这份诊断日志保存在当前 Zotero 会话的内存中，不写入配置文件。可以从“帮助 > 报告 Mktero 问题”、转换失败时的“报告问题”按钮，或 Mktero 标签页的文档操作菜单打开。复制和保存只会在这台电脑上生成脱敏文件；这一版不会上传。“打开 GitHub Issue”只在浏览器里打开空白的 Issue 表单，不会发送报告内容。文件可以包含插件版本、Zotero 版本、操作系统、转换服务、解析配置标签、论文的条目 key、它最近一次转换失败的错误码、转换任务号、你填写的说明，以及脱敏后的日志。它不会包含 API key、账号令牌、账号邮箱、PDF 字节或文件路径。退出 Zotero 后日志即丢弃。

版本上报只包含插件自身的版本号，在登录、刷新令牌或后台心跳时发送给 Mktero 服务，不包含设备指纹、硬件、操作系统或由 IP 推导的标识，也不接入任何第三方统计。版本号不会附加到发往对象存储、MinerU 或 Mistral 转换服务，以及你配置的 AI 或引用 Provider 的请求上。它不属于你的账号资料，因此任何产品界面都不会把它展示给你。

调研邀请由 Mktero 服务发送，不是插件发送的。插件不发送也不保存调研回复。可以在网站账号页关闭调研邀请；增加这个开关之后发出的邀请邮件里也有直接退订链接。关闭后不影响验证码、密码重置和论文转换，也不会删除已经提交的回复。

主动请求未缓存的转换且使用默认转换服务时，完整 PDF 会发送到已登录账号所使用的 Mktero 服务。请同时阅读该服务的数据处理方式，以及你改选的 MinerU、Mistral、AI Provider 和引用 Provider 的隐私政策。除非相关数据处理条款符合你的使用场景，否则不要处理机密 PDF。
