# 注释、笔记与校对

[English](./annotations.md) · [简体中文](./annotations.zh-CN.md) · [返回 README](../README.zh-CN.md)

从 Markdown 创建注释，在论文旁编辑 Zotero 笔记，并校对识别错误，缓存的 OCR 原始结果保持不变。注释指 PDF 注释或本地 Markdown 高亮，其文字字段称为评论；笔记仅指 Zotero 笔记条目。

## 从 Markdown 创建注释

打开文档时会加载已有的 Zotero 文本高亮和下划线。添加注释的方法：

1. 拖选标题或正文，包括紧接图片、行间公式之后的文字。也可从论文引用、图表引用或脚注标记开始拖选；不拖动的单击仍会打开对应引用。
2. 在选区弹窗中选择`添加高亮`。本地注释会立即出现；只有本地 PDF 文字索引找到唯一可靠的位置后，Mktero 才会创建对应的 Zotero PDF 注释。
3. 在注释弹窗中修改颜色，选择`添加评论`、`编辑评论`，或删除注释。

尚未同步到 PDF 的本地高亮显示虚线下划线；同步失败时显示点状警示下划线，悬停可查看原因。重复或有歧义的文字保留在本地，可以重试，不会被放到猜测的位置。

左栏的`注释`分段列出论文注释，支持搜索、颜色筛选、跳到 Markdown 位置、`在 PDF 中查看`、删除、为本地高亮`重试同步到 Zotero`，以及`添加至笔记`。

## 在阅读器旁写 Zotero 笔记

左栏包含`标题`、`图表`和`注释`三个分段。右栏是`笔记`，分为两个标签：

| 标签 | 显示的笔记 |
| --- | --- |
| `条目笔记` | 当前论文的子笔记，最新的在前 |
| `独立笔记` | 同一 Zotero 文库中的顶层笔记，最新的在前 |

其他论文的子笔记、其他文库的笔记均不显示。笔记栏可搜索标题或内容摘要，不列出 `Mktero Markdown Snapshot` 笔记。

### 打开或新建笔记

1. 点击笔记，在 Mktero 标签页内使用 Zotero 自己的笔记编辑器编辑；也可打开加号菜单，选择`新建当前条目笔记`或`新建独立笔记`。
2. 用`返回笔记列表`回到列表，或用`在独立窗口编辑`打开 Zotero 笔记窗口。
3. 在列表中右键笔记，可选择`在文献库中显示`（在文献库标签页选中该笔记）、`在独立窗口编辑`或`移动到回收站`。移入回收站的笔记仍可在 Zotero 中恢复。

两类笔记都是普通的 Zotero 笔记条目，由 Zotero 负责同步、搜索和恢复；Mktero 不存储笔记。[文库权限与编辑器回退](#在阅读器旁写-zotero-笔记-1)见下文。

### 把段落和注释添加到笔记

先在`笔记`栏中打开目标笔记，也可以是独立笔记。再从选区弹窗、注释弹窗或`注释`分段中的单条注释选择`添加至笔记`。

插入方式与 Zotero PDF 阅读器一致：高亮文字、一条引用和页码。点击笔记中的引用会打开 Zotero PDF 阅读器。添加普通选区不会保存高亮。

插入需要已打开的笔记和 PDF 位置。本地高亮尚未同步到 PDF，或本地 PDF 索引无法定位选区（找不到或有歧义）时，会拒绝插入并说明原因；Mktero 不会插入没有来源的文字。

需要集中整理注释时，选择`注释`分段中的`从注释添加笔记`。它与 Zotero 同名命令一致：新建一条子笔记，包含该 PDF 除手写注释以外的全部注释，并在`笔记`栏中打开。

## 校对识别错误

1. 在工具栏末尾的文档操作菜单（`⋯`）中选择`管理校对`，工具栏下方会出现操作提示条。
2. 双击已有段落、标题或 GFM 表格单元格进行编辑。用`保存修改`保存，或按 `Escape`、点击`取消`放弃。
3. 校对模式下也可删除和恢复已有段落、标题。
4. 点击提示条的`结束校对`退出校对模式。

关闭标签页、主窗口或 Zotero 时，仍打开的编辑会保存。保存后保留阅读位置，滚动时整篇文档仍可正常显示。校对不能插入或重排内容块，也不能添加图片或原始 HTML。

校对独立于不可变的转换缓存。[校对规则](#校对识别错误-1)说明身份、受保护文字、数据恢复和确认框；[翻译规则](./reading.zh-CN.md#使用-ai-翻译-1)说明已翻译内容块如何处理。

## 细节

### 从 Markdown 创建注释

#### 选区文本与定位

保存的文本遵循阅读器的显示内容：

- `$^{*}$` 等上标保存为对应符号。
- 跨两个表格单元格的文字之间保留空格。
- 不写入链接标题。
- 公式保存为 TeX，图注和表格单元格中的公式也一样；高亮覆盖渲染后的公式。

选区被拆成超过 512 段时，会提示并拒绝保存，不会保存不完整的注释。高亮与论文引用、表格引用或图表引用重叠时，这些引用优先响应；仍可从周围的高亮文字或评论标记打开注释操作。

常见的 MinerU LaTeX 数学符号和简单下标会归一化为 PDF 提取文字的形式。匹配也会容忍 PDF 文字层抽错的少量字符，因此含公式的选区仍可定位。行间公式的 LaTeX 无法从文字层还原时，回退到该内容块记录的 OCR 区域。

跨页选区按页拆成单页 Zotero 高亮，整段 Markdown 选区仍可导航。段落隔一两页才继续时也能按同样方式定位，不受中间整页图片或页脚影响。

#### 跨页分组

在 Markdown 中修改某一段的颜色或删除它，会同时作用于 Mktero 为这次选区创建的所有分段。评论仍留在写下它的那一段。

Mktero 在 Zotero 配置目录的 `mktero-annotations/groups-v1` 中保存分组关系，只记录 Zotero 注释 key。与已有 Zotero 高亮匹配的分段不会被这样分组或删除；已在 Zotero 阅读器中删除的分段会跳过。分组功能提供之前创建的跨页高亮没有分组记录，仍逐段修改。

#### 本地注释无法读取

已保存的本地注释未能完整读取时，Mktero 会把原文件备份为 Zotero 配置目录 `mktero-annotations/v1` 中的 `item-<id>.corrupt-<timestamp>.json`。随后显示提示，保留仍可读取的注释，并继续接受新注释。

### 在阅读器旁写 Zotero 笔记

#### 权限与编辑器回退

所有笔记操作遵守笔记所属文库的权限。没有父条目的独立 PDF 可以显示和创建独立笔记，但不能拥有子笔记。只读文库中的笔记以只读方式打开，不能新建或删除。

如果 Zotero 无法在标签页内显示笔记编辑器，笔记会改在 Zotero 笔记窗口中打开。

#### 添加段落中的公式

随段落插入的公式成为可渲染的笔记公式。Zotero 高亮不能包含公式，因此高亮会在每个公式前断开、之后接续；行间公式独立成块。文字保留高亮颜色和页面链接，公式本身没有颜色或链接，PDF 中的原注释不变。

以下情况保留 Zotero 的纯文本：

- 跨页段落。
- Mktero 无法在 Markdown 中定位的注释。
- 文字与当前位置不再匹配的注释。

如果 Zotero 笔记编辑器发生无法识别的变化，会回退到 Zotero 原本的插入方式，不渲染公式。`从注释添加笔记`先由 Zotero 写入笔记，再由 Mktero 按相同规则补入能在 Markdown 中定位的每条注释的公式，并保存一次。

#### 侧栏与布局保存

选中 Mktero 标签页时，会隐藏 Zotero 右侧条目面板（上下文面板）；切换到其他标签页后恢复。Zotero 不会为 Mktero 标签页更新该面板，否则它仍会显示前一个标签页的论文。

哪些栏打开、栏宽和左栏选中的分段保存在 Zotero 首选项中：`extensions.mktero.readerOutlineVisible`、`readerOutlineWidth`、`readerOutlineSegment`、`readerNotesVisible` 和 `readerNotesWidth`。下一个 Mktero 标签页会沿用这些设置；窄窗口触发的自动收起不会保存。

### 校对识别错误

#### 身份与无法读取的数据

校对绑定 PDF 内容及所选来源的解析配置；导入结果还会区分具体导入快照。保存的校对无法读取时，文档以原始识别结果打开并显示提示；下次保存校对或重新解析会替换无法读取的数据。

#### 受保护内容

公式和 OCR 使用美元符号包裹的引用标记受保护，周围文字仍可编辑；含受保护内容的整块不能删除。渲染后的 GFM 表格中，含受保护内容的单元格只读，其他单元格可编辑。

与注释匹配的文字也受相同保护。修改前需先删除注释，前后文字仍可编辑；Mktero 会更新注释锚点，使重新打开后仍能匹配。恢复校对若会改变已有注释覆盖的校对文字，会被拒绝。

#### 恢复或重新解析

`恢复全部校对`或重新解析含校对的 PDF 时，会出现阅读器内的 Mktero 确认框。按 `Escape`、点击遮罩或使用默认聚焦的`取消`，文档均不改变。重新解析行为见[转换与本地缓存](./conversion.zh-CN.md#标签页取消与重新解析)。
